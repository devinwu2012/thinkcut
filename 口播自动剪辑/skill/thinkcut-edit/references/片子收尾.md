**给用户看的内容不写成 MD**（2026-11-21 用户：“以后少用md文档跟我沟通……不然就对话框里或者claude 文档也行”）：交付清单、目标、给用户的说明和建议都在对话里列或写 Claude 文档。收尾时跑一次 `status DIR`，`02_制作` 下有这类 MD 它会提醒：只看 `02_制作` 和片子目录这两层，文件名含“交付清单”“交付说明”、以“V数字…目标”开头、以“给用户”开头、或含“建议”的 `.md` 才算；程序要读的 `反馈记录.md`、项目文案 `<项目名>.md`、`口播文案.md`、`片子复盘.md`、`给架构审查_*.md` 不算。已有的问用户要不要挪走，别自己删。

## 1. 写片子复盘

写 `<项目文件夹>/02_制作/片子复盘.md`；已有就在文末加一节，标上日期，不覆盖旧的。按这个格式，没有的项写“无”：

```markdown
# <项目名> 片子复盘（YYYY-MM-DD）
反馈人：<姓名>   做到哪一步：剪口播 / 动画 / 字幕导航 / 花字音效 / 导出 / 封面 / 上传
3 个数：审核 N 轮；用户先发现 N；AI 自查先发现 N（数 02_制作/反馈记录.md）

## 动画清单（给“动画案例索引”用）
- 代码位置：<项目>/02_制作/自动剪辑/动画/（镜头代码在哪个文件、公共底层在哪个文件）
- 风格：暗场白模＋蓝紫信息色 / 其他（写清哪里不同）
- 怎么单独看一个镜头：<命令或网址参数>
| 镜头 | 讲什么 | 画了哪些东西（物体、原理、手法） | 沿用了哪条旧片的镜头 |

## 卡点和返修
- 用户审核时改了什么：哪一句 / 哪个时间码，原来怎样，改成怎样，为什么（用户原话尽量照抄）
- 卡点不准、字幕错字、音量、导航、花字等问题，各一条

## 工具问题
- 哪一步报错、慢、要手动补、绕了远路：命令、报错原文、最后怎么解决的

## 用户这次新定的规矩
- 原话＋适用范围（只这条片子 / 以后都这样）
```

动画清单照实写，镜头清单从 `分镜规格.json` 和实际画面对出来，不凭印象。
