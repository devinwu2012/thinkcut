原「必守规则」里只管老代码动画的三条：

3. （仅老片子：老的代码动画）`renderAt(t)` 必须确定：同一个 t 每次画面一样；不用 `Math.random()` 或真实时钟。

### 1. 工程与必须遵守的接口（仅老片子：老的代码动画，2026-11-20 起新片子停用）

动画是一个 Three.js 三维网页。`build.py` 按文件名顺序拼接 `src/*.js`，连同 `timeline.js`、排版结果、分镜和 `vendor/` 中的依赖，生成可离线打开的单文件 `动画.html`；出片用无头 Chrome（不开窗口的浏览器）逐帧截图。

- 页面准备好后设 `window.__ready = true`；出错时通过 `window.__err` 留下错误，保留 `shell.html` 的错误监听。
- `window.pipe.capture(t)` 返回 t 秒那一帧的 JPEG 数据网址。随机细节用固定种子的 `U.rng`，运动由 t 计算；播放控件的时钟不参与指定时刻的画面状态。
- 网址参数：`mode=beats` 按编译后的 `分镜.json` 卡点出片；`fmt=p|v|h` 分别是 3:4、9:16、16:9；`w` 指定实际出图宽度，4K 时 p/v 用 2160，h 用 3840；`ui=0` 隐藏播放控件；`clean=1` 去掉所有文字和控件。
- 逻辑像素是排版用的内部坐标：p/v 宽 1080，h 宽 1920；出 4K 时都乘 2。横屏别按 1080 宽算。
- 16:9 卡点模式的卡片是通栏（逻辑坐标 x40 y120 宽 1840 高 800），上面留给导航条，下面留给字幕带。“示意”小提示用 `OV.chip`，留在卡片左上角。
- `src/25_setup.js` 的 `CARD` 是三维卡片区域；`src/62_beats.js` 的 `PIP`、`pipX` 是人脸小圆圈预留位置。乘 2 后必须和 `scripts/thinkcut/formats.py` 的卡片、小圆圈一致，圆圈区域不放标签。

### 2–4. 新题材的镜头怎么写（仅老片子）

（路径相对 `DIR/动画/`；文件分工、画面手法见本文件第三部分。）

1. 新题材一般不用 `warp`（烟道先做成连续动画、后来才按卡点，用 warp 把新卡点映射到旧 `timeline.js` 的段），直接按 `分镜.json` 的镜头 id 写。
2. 在 `SH_CAM` 为每个动画镜头写相机起点、终点：各是 `[位置, 对准点, 视角]`。`shotsBeats` 用 `kf` 变成关键帧，再交给 `camAt`；替换烟道硬切分支和默认相机。
3. 在 `stateBeats(t)` 按镜头 id 算状态。卡点名来自 `分镜规格.json` 的 `anchors`，经 `beats` 编译成秒数后，代码里用 `BA.<卡点名>`；`pop` 做弹出，`on` 做淡入，`ramp` 做一段平滑进度。说到哪个词，动作就在那一刻出现，用 `BA` 定开始和结束，不凭观看感觉估时间。
4. 在 `beatsOverlay` 按镜头 id 写标签，用 `OV.tag` 标物体、`OV.chip` 加必要提示；在本期的 `applyState` 把状态应用到场景。
5. 新题材直接从空状态开始，补齐本期 `applyState` 要读的字段，不继承烟道施工进度（烟道的 `stateBeats` 用 `SH_REF` 找旧段、`stateAt0(T(...ref))` 借施工状态）。

**坑：时间会绕回开头。** `src/70_play.js` 的 `renderAt` 先执行 `t = ((t % DUR) + DUR) % DUR`；`DUR` 是 `src/60_director.js` 累计 `timeline.js` 各段 `dur`。总长至少等于成片长度，最简单写一段、`dur` 设成成片秒数；不足时后段会绕回开头重放。单段时间线要清理旧段号引用：`SCENES`、`INS`、`PANEL` 等仍有 `T(12, ...)` 一类调用，不能只改 `timeline.js` 就出帧。文件按名字顺序拼接，重写时保持对象先创建、后使用。

### 5. 做法与坑（仅老片子）

- 先定“一眼看懂”：观众先认出是什么，再讲结构、问题和做法。拆解从原位开始，讲完放回，不能凭空出现一块板。
- 结构用斜角三维剖开或半透明，不用正对的平面剖面。分层可放大厚度，但要标“示意：各层厚度已放大”。剖切平面只切掉表面、不自动封口；剖开或挖洞后要补截面和洞边厚度，否则会看穿。
- 同种材料全片同色，在 `PAL` 定本期材料（烟道举例：防水膜蓝绿、防火堵料红、漏进家里的烟橙）。
- 镜头连续平滑；硬切只用在有意卡词切特写的地方。
- GTAO（屏幕空间环境光遮蔽）在烟道场景出现过方格瑕疵，已弃用；墙角暗影用 `aoStrip` 渐变条。
- 标签排版：卡点模式排版存 `layout_pb.json`、`layout_vb.json`、`layout_hb.json`（3:4、9:16、16:9）。`分镜.json` 比当前画幅排版新、或排版文件不存在时，`anim-build`、`anim-render` 自动重排；只改场景、相机或标签 JS 不触发，要手动重排：在 `DIR/动画/` 内运行 `NOLAYOUT=1 python3 build.py < /dev/null && node tools/layout.mjs pb < /dev/null && python3 build.py < /dev/null`（9:16 换 `vb`，16:9 换 `hb`）。
- 不用清单就别调用 `OV.pList`（`STEPS7` 不会自动变成本期步骤）。
- 换口播后分镜变了要重新 `anim-build`（`动画.html` 把分镜写死在里面）；`anim-render` 每次都先 build。
- 出片：`anim-render` 只画代码动画自己的镜头（实拍/图片镜头、别的工程的镜头不碰），每个镜头出到 `动画/出片/<镜头>.mp4`、登记进 `合成/动画清单.json`，再由 `anim-assemble` 逐帧拼成 `合成/B肉.mp4`（其余帧黑帧）。
- **审片轮只出 1080P，几段同时出**（2026-11-21 用户：“直接1080P就行了。等我们都确认好了，最终导出的时候都渲染4K”）：`anim-render DIR` 不带参数就是半尺寸（3:4 是 1080 宽，2026-11-21 Q159 复发后改成默认），出成 `动画/出片/<镜头>_预览50.mp4`、登记 50%，不动 4K 那份；用户看完 OK、导出前才加 `--4k` 重渲 4K（`export` 见到 50% 的会拦）。两种都把镜头切成 ≤40 帧一段、几个 Chrome 同时出（默认按本机核数：预览最多 10 路、4K 最多 8 路，`--workers` 可改；《别墅装灯》实测 4 个镜头 1080P 10 路 209 秒、4K 8 路 329 秒）。
- 出片防卡死、防首帧黑（2026-11-12《水电》A20 卡过 4 小时、首帧黑过三次）：每段开新 Chrome、限时（启动 60 秒＋每帧 1.5 秒），单帧 30 秒没出来就杀掉重来（最多 3 次）；`cap.mjs` 就绪后先把第一帧画一遍丢掉再截；出完查第 1 帧是不是比第 2 帧暗一大截。几个 Chrome 同时开时各用各的调试端口（程序分配），不会截到别人的页面；`cap.mjs` 截完马上退出（2026-11-21 前每开一次 Chrome 截完都要白等 30 秒）。

#### 5b. 自查（仅老片子）

- 新题材第一次出帧前，确认 `hotObjects()`、`shaftSoft()`、`STEPS7`、`<title>` 已按本期替换或停用，`timeline.js` 总长已覆盖本期成片。
- `anim-stills DIR --t 2,25,60` 抽帧（时间换成本期关键时刻，并查最后一个动画镜头，防止绕回开头）：卡点时刻画面对不对、标签有没有压到东西、小圆圈的位置是不是空的。
- 拿 `合成/A肉.mov` 对照听：说到那个词时，那个动作正好出现。

### 通用画面手法

这里学的是呈现方法；参考段落里的烟道坐标、物体名和卡点都要换成本期的。

| 烟、粉尘或火说明流动 | `Smoke.free` 自由发射，`Smoke.path` 沿路径走；固定种子，由指定时刻算粒子，同一时刻每次一致 | `src/40_smoke.js` 的 `Smoke`；调用参考 `src/65_apply.js` 的 `smokeFrame` |
| 让材料一眼可辨 | 用程序贴图增加纹理，同种材料全片同色，材料色集中在 `PAL` | `src/20_tex.js` 的 `TEX.surface`、`TEX.tiles`、`TEX.paint`；`src/25_setup.js` 的 `PAL` |
| 墙角需要暗影增强体积 | 贴沿墙角线最暗、向外渐淡的条，不用 GTAO | `src/30_scene.js` 的 `aoStrip`、`buildAO` |
| 连续运镜，必要时强调词语 | 关键帧间用 `hermite` 平滑；明确卡词时才硬切或轻抖。烟道在“接缝”切特写，在“松动”轻抖 | `src/60_director.js` 的 `hermite`、`camAt`；`src/62_beats.js` 的 `shotsBeats` 中 `B_hole`、`B_old` |
| 说到那个词，动作正好出现 | 用 `BA.<卡点名>` 定动作开始和结束，不凭观看感觉估时间 | `src/62_beats.js` 的 `BA`、`pop`、`on`、`ramp`、`stateBeats`、`beatsOverlay` |

例如讲剪刀：先广角认出剪刀，再斜角半透明看刀轴，再原位拆下螺丝、分层拆开；场景和动作按剪刀重新写。

## 四、10-23 上午定的旧风格（原 动画风格.md 三节，仅作历史参考）

现行风格以 动画风格.md 开头三条为准；「物理必须对」「定稿规则」「被否掉的方向」仍然有效，还在 动画风格.md 里。

### 旧：电影暗调＋暗场悬浮爆炸

用户要写实、有视觉冲击力的动画，选了两种风格搭配。

（10-22 第一次试 Blender，用户评价“几乎都违反物理定律”——问题在物理和布局常识，不在 Blender 本身；11-12 起 Blender 重新收进来，配物理清单和布局检查。）

### 主风格：电影暗调

用在讲问题、讲场景、讲施工的镜头。

- **画面**：场景几乎全黑。一束暖色硬光从窗外或侧上方斜着打进来，空气里有薄雾，光束看得见，光束里有浮尘。阴影偏冷青，高光偏暖橙。
- **问题点**：漏出来的臭气、油烟用带一点主题橙（#FF6F00）的烟，自身微微发光，让观众一眼看到问题在哪。
- **远近成套**：全景用低机位广角，剖开看空间，被照亮的地方是重点，其余沉在暗里；中景视角收窄，压暗；特写视角更窄，加一盏贴着表面的掠射光，把缝隙和材料质感照出来。特写不放浮尘，免得挡镜头。
- **代码做法**：`renderer.toneMapping` 用 ACES，曝光压低；场景雾用深色；光束用叠加混合的半透明锥体，边缘渐淡；浮尘用固定种子的发光小点；暖色聚光灯开阴影，冷色补光很弱。

### 讲部件、讲材料：暗场悬浮爆炸

讲一个部件的内部构造或一层层材料时切到这种。

- **画面**：房间全部藏起来，只留要讲的部件，放在纯黑背景上；地面是黑色镜面，有淡淡倒影。左冷、右暖两盏轮廓光，加一盏顶光，背后一圈冷色光池。
- **拆开**：零件沿同一条轴依次飘开，停稳后挂标签，讲完再合回去。厚度放大时标“示意：厚度已放大”。
- **远近成套**：全景看到全部零件；特写对准要讲的那个零件。
