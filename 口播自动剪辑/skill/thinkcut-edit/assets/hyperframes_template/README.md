# HyperFrames 网页动画模板

用 `thinkcut_edit.py hf-new 片子目录 名字` 复制到片子目录（`HF_名字/`），不要在这里直接改。完整做法见 `references/动画做法.md` 第 7b 节。

- `镜头/示例.html`：一个镜头的写法。复制改名成镜头号，只改内容和时间轴。
- `共用/基础.css`、`共用/基础.js`：字体、配色、画面区位置、卡点换算、名称标签 `THINKCUT.label`（字在目标点正上方、一条竖线；两个标签先后出现）。`共用/gsap.min.js`（动效）、`共用/three.module.min.js`（三维）。
- `共用/距离圈.js`：讲异地、多城市、离得多远用的组件 `THINKCUT.distanceRing`（2026-11-21 从《装修最后那点细节》B01/B03 收进来，用户：“不要把地图画那么明显……能看清楚是个异地的感觉就行”）：圆心城市＋几圈虚线距离圈，城市按真实直线距离和方位摆，弧线、小飞机、落点、标签卡；不画任何地图边界（标准地图要审图号，编辑要送审）。在镜头文件里 `共用/基础.js` 之后引入，写法和参数见文件开头和 动画做法.md 第 7b 节。
- `出片.py`：预览、样张（出完拼成一张图在“预览”里弹出，并打印“请看哪里、确认什么”）、整段出片（默认 1080P 审片版，导出前加 `--4k`）、透明版、登记。
- `hyperframes.json`、`package.json`、`meta.json`：HyperFrames 认工程用的，不用改。

模板在 HyperFrames 0.9.39 上验证（2026-11-20）。
