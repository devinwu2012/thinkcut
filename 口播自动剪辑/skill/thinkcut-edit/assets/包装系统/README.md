## 怎么调用（剪辑时）

1. 在片子目录（有 `口播字时间.json` 的那个，一般是 `02_制作/自动剪辑/`）写 `花字.json`：一个列表，每条一个花字。`at`、`until` 写**口播原话**（在上一条之后找这几个字开口的那一刻），也可以写秒数；子项（items/steps/rows/bars/race）的 `at` 也写原话。
2. 跑：
   ```
   python3 <程序目录>/口播自动剪辑/skill/thinkcut-edit/assets/包装系统/huazi.py <片子目录>          # 全部出
   python3 …/huazi.py <片子目录> --only 3,5                                                              # 只重出第 3、5 个
   ```
   → `合成/花字/NN_组件.mov` ＋ `合成/花字/花字表.json`（每条：n、use、kind 文字/卡片、file、start/end 成片帧号、at/until 秒；`warnings` 是违反克制档规矩的提示）。
3. 审核线“花字”轨按 `花字表.json` 放（放置程序归 thinkcut_edit review）。有花字的那几句，字幕去掉或不再标蓝（不重复强调）。
4. 每个花字配一个轻音效（POP / TICK），已有节拍音效的同一时刻不再加。

## 统一规范（所有组件共用，不许单个改）
| 项 | 定值 |
|---|---|
| 字体 | 苹方 SC（PingFang SC）：标题/数字 中粗 Semibold，单位 Medium，说明 Regular。全库只用这一种字体（例外：人挡字，见最后一节） |
| 颜色 | 蓝白两色：正文白；次要文字白 85%；弱化（反例）白 47%；**唯一强调色 #64A9E8**（和字幕重点词、导航条同一个蓝）。不用黄、渐变；**红 #FF5C5C 只给口播大字〖〗里的“反面”词**；**橙色只留给下划线、手画圈** |
| 底 | 默认无底色，只有柔和投影；成组数据才用深色半透明圆角卡（66% 黑，圆角 40，1px 白 14% 描边）；卡片单独占一个镜头时 `bg: true` 铺满 #16181D 一类的深底 |
| 进场 | 0.40 秒缓出：透明→不透明、上移 28px、模糊 10→0；多项依次间隔 0.12 秒 |
| 出场 | 0.30 秒缓入：变透明、轻微模糊，不移动 |
| 数字滚动 / 线条生长 | 0.80 秒 / 0.50 秒 |
| 停留 | 最少 1.5 秒；没写 until 就停 3.0 秒 |
| 禁止 | 弹跳、回弹、抖动、闪白、砸屏、倾斜、描边大字、表情包、弹幕 |
| 字号（3:4 和 9:16 的值；16:9 全部乘 0.92，见上面的画幅表） | 大数字 230；关键词 104；卡片数值 96；正文 76；说明 70；小字 64；金句/口播大字 124 |
| 安全区 | 3:4：左右各留 120；上边 y≥420（导航条下）；下边 y≤2400（字幕上）。9:16、16:9 见上面的画幅表 |

## 12 个组件（用在什么场景）
| 组件 | 类 | 用在什么时候 | 不要用在 |
|---|---|---|---|
| **number 数字强调** | 文字 | 口播说出**一个关键数字**：价格、尺寸、数量、时长 | 一句话里 3 个以上数字（用 spec） |
| **keywords 关键词** | 文字 | 口播在**并列列举**几个要点，说到哪个出哪个 | 只有一个词（交给字幕重点词变蓝） |
| **note 提示** | 文字 | tip：**提醒/注意事项**；source：**画面出处** | 长句（超过 14 个字就拆或改用字幕） |
| **leader 引线标注** | 文字 | 实拍画面里**指出一个具体部件**，点在部件上，字放空的一侧 | 口播露脸画面；动画（动画用 biaoqian.py） |
| **statement 金句** | 文字 | 全片的**主题句、结论句**，关键词变蓝。**一条片子最多 2 次** | 普通句子 |
| **koubo 口播大字** | 文字 | 露脸段强调口播要点、替代那几条字幕；多行在说到那句时逐行出现，整组位置不跳；中心默认在胸口（3:4 是 y=2000，9:16、16:9 见上面的画幅表）。`【】`里的词蓝；`〖〗`里的“反面”词红 #FF5C5C（11-12 用户看样张后定，和蓝色的正面词一红一蓝） | 实拍段 |
| **comment 评论弹窗** | 文字 | 开头展示评论区反应：半透明白卡＋卡通头像（`mood: angry` 生气头像），放在脸的两边、不盖脸，逐条按统一节奏出现（原来的回弹改掉了） | 不加“评论大意示意” |
| **spec 参数卡** | 卡片 | 一个东西有 **2–4 个参数要一起记** | 只有 1 个数字（用 number） |
| **compare 对比** | 卡片 | **A 不行、B 才对**：错误做法 vs 正确做法 | 两边差不多、没有对错 |
| **steps 步骤卡** | 卡片 | 有**先后顺序的操作**。两种样式（`"样式"`）：**并排**（2026-11-21 起新片子默认，《别墅装灯》用户定）——先出第 1 步，说到第 2 步时 1、2 并排，再说到第 3 步时 1、2、3 并排……每步一张小卡（蓝色序号圆＋步骤名），已出的保留，整排始终水平居中，**不露后面还有几步**；默认在胸口高度（同口播大字），可写 `anchor`/`dy` 挪，太宽自动缩进安全区。**连线**（老样式）——①—②—③ 圆圈连线一次全画出来，说到哪步亮哪步。11-21 以前出过花字的片子（`花字表.json` 里没记 `步骤卡默认`）仍按连线出，重出不变样；单条写 `"样式"` 优先 | 没有顺序的并列（用 keywords） |
| **jigexian 及格线** | 卡片 | 讲**档位**：哪档不能用、哪档是底线、哪档最好。一条虚线“最低标准”，线下灰色划掉，线上白色，往上蓝色＋升级箭头；说到哪档出哪档（《水电》A20 用户选定） | 只有好坏两档（用 compare） |
| **wangsu 网速对比** | 卡片 | 讲**数值差距**：横条长度按真实数值等比（`v` 填真实数），说到哪根长哪根；可加“进度条赛跑”（同一件事各档用时 `sec`，最快那档 1.3 秒跑满，其余按用时等比只跑到对应进度） | 数值差太小看不出差别时（改用 spec） |

讲关系、对比、档位的卡片和动画一样，**做之前先出逻辑草图静帧给用户确认**（见 `references/动画做法.md` 第 6 节）。

## 什么时候放、放多少（克制档）
1. **同一时刻画面上最多 1 个花字**（字幕、导航条、人脸圆圈不算）。
2. 两个花字之间至少隔 **3 秒**；全片大约 **每 20–30 秒一个**；金句全片 ≤ 2。（`花字表.json` 的 warnings 会提示）
3. **动画镜头里已经有大字/标签的那一刻不再叠花字**（只看那一刻：动画自己没有大字的时刻照样可以配；全动画的片子怎么配见 `references/初稿模式.md` “全是动画的片子也要有花字”，2026-11-24）。
4. **不挡脸**：口播露脸段放右上 TR / 左上 TL 或字幕上方；有人脸小圆圈的实拍段放在圆圈的对角。16:9 人在画面中间，默认“顶部居中”的卡片程序已改放左上，自己写 `anchor` 时也别放正中上方。
5. 花字强调过的词，字幕里就不再标蓝（不重复强调）。**程序自动做**（2026-11-23 初稿模式实测）：`subs` 读到花字表时，和花字同时出现的那几句不标蓝——先出花字再出字幕；顺序反了 `check` 报“有花字的句子字幕还标蓝”，重跑 `subs`。
6. 数字、价格必须和口播原话一致（不四舍五入、不换单位）。
7. **初稿也要过这两项**（2026-11-23，`check` 会报、算自检不过）：两个花字同时出现或之间不到 3 秒（`huazi.py` 出片时的提示不能略过：留更重要的那个、合并成一个，或把前一个的 `until` 提前）；文字类花字的白字压在浅色画面上看不清（换 `anchor` 到画面里深色的位置、换带底的卡片组件，或把那个镜头的图换成深一点的）。

## 开源库里没选的（和原因）
- 开场 / 钩子（TeaserColdOpen、SlamText 原版、TextBehind 等）——太“综艺”或不适合特写口播。
- 网感互动（弹幕、表情、梗图、投票、故障插屏）——和“克制”相反。
- 证据类全屏（EvidenceCard、DocFocus、MapRoute 等）——本频道 B-roll 以实拍和动画为主，需要时再单独做。
- 人物类（LowerThird、NamePlate 等）、结构类（ChapterCard、RecapBoard）——单人口播用不上；已有章节导航条。
- 5 套剪辑风格里最接近现在做法的是 **C 发布解读的“克制”版（MKBHD 式：字少留白，只给数字、关键词、出处）**，节奏参考影视飓风/何同学：约 3 秒一个视觉变化，由 B-roll 和动画撑节奏，花字只做点睛。

## 人挡字风格库（2026-11-13 用户定）
**人挡字**＝特别重点的大字放在人后面，人挡住字的一部分。用户看了第三轮样张定 4 套都进风格库（“这 4 个都可以作为风格库放在里面”），**每条片子用一套**。用户认可的四套总览图、和正式程序的对照图、调研和定稿过程都在 `人挡字样张/`。

| 套 | 特点 | 适合 |
|---|---|---|
| 1 苹果式静默大字 | 思源黑体细、纯白、占画宽 58%；背景压暗 15%；0.8 秒浮现上移，停留时每秒放大 1% | 干净、偏暗的背景；一个概念、一个结论的“定场” |
| 2 杂志刊名压头 | 思源宋体特粗撑满 90% 画宽，上方可加一行小字；硬切出现；整体胶片调色＋颗粒＋暗角 | 章节开头、“第二件事”这类刊名式标题；背景亮、字多也压得住 |
| 3 镜头对焦字 | 思源黑体特粗白字、占宽 70%；0.6 秒从模糊放大收到清晰，背景同时虚化 16px | 背景乱（窗外、杂物）；强调“关键在这” |
| 4 超大出画面＋遮罩升起 | 思源黑体特粗、深蓝灰 88%、占宽 118% 左右出画；每个字从底线下面升起 | 亮背景、头顶空间紧；2–3 个字的短词 |

**做法**：这些处理作用在整个画面上，所以每处出一段**不透明的整幅 4K 片段**（口播画面那一段 → 压暗/虚化的底 → 大字 → RVM 抠出来的人 → 整体调色），和口播画面同帧率、同尺寸、逐帧对齐，帧数＝起止帧差。审核线放“花字”轨盖住那段口播画面（花字轨在导航、字幕下面，它们照样压在上面），声音用口播原声。抠人调 `口播剪辑/engine/fx/matte.py` 的 `generate()`（只调用不改），缓存在 `合成/花字/人挡字抠像/`。

**取景要和审核线一样**（2026-11-21，《别墅装灯》审核线人像手调下移 230 像素，人挡字用的底片没下移，盖上去画面跳一下）：人像要整体往下挪，就在 `job.json` 写 `"人像下移": 230`（4K 像素，正数往下），然后重跑 `aroll-render`：除了 `合成/A肉.mov`（小圆圈、检查图用，不变），同一遍再出 `合成/A肉_人像下移230.mov`（裁切框往上挪，挪出源画面的部分补黑，和达芬奇露出的黑边一样）；人挡字自动用这一份，`review` 建审核线时也按同一个值给口播画面设 Tilt。不要在达芬奇里手调人像位置（重建审核线会丢，人挡字也对不上）。`aroll-render` 出完直接跑 `huazi.py` 就行：同一遍出的两份写完有先后，程序按 `合成/A肉_批次.json`（每遍 `aroll-render` 记下这一遍出的文件）认同一批，不按修改时间判谁旧，不用手动 touch（2026-11-21《装修最后那点细节》：下移那份早写完 41 秒，被误报“比 A肉 旧，先重跑 aroll-render”）；只有 `A肉.mov` 之后又单独重出过才会叫重跑。达芬奇里对口播**调色**后，人挡字这段要重出或同样调。

**怎么选风格**：`job.json` 写 `"人挡字风格": 1–4 或套名`，整条片子都用这一套；单条可写 `"风格"` 覆盖。**没写就自动选**（2026-11-14 用户定：不停下问，不合适再换）：第一处人挡字出片时，看那一段露脸画面里大字要放的那一带（导航条下到头顶下面一点）去掉人以后的背景，从上往下第一条成立的就选它，写回 `job.json`（`"人挡字风格来源": "自动"`，依据也记下），之后整条片子沿用；输出里一句话说明选了哪套、为什么、怎么换。用户手写的永远照用。同样的画面永远选同一套。
| 条件（按顺序） | 选 | 理由 |
|---|---|---|
| 背景乱（平均梯度 ≥ 3.0） | 3 镜头对焦字 | 虚化把乱背景压下去；细字、深色字在乱背景上会被吃掉（户外细字在窗前偏弱） |
| 背景亮（平均亮度 ≥ 150）、字 ≤ 3 个 | 4 超大出画面 | 白字在亮背景上发虚；深色巨字在亮底上最清楚 |
| 背景亮、字 ≥ 4 个 | 2 杂志刊名 | 胶片调色压暗、宋体笔画粗；超大出画面字多会切掉太多 |
| 头顶紧（头顶 y < 700，4K）、字 ≤ 3 个 | 4 超大出画面 | 本来就压在头后、放得最高，最不用退 |
| 头顶紧、字 ≥ 4 个 | 2 杂志刊名 | 刊名本来就压头，字多也撑得住 |
| 其余（干净、不亮、头顶有空） | 1 苹果式 | 最克制 |
阈值按第三轮素材量过：《水电》室内浅灰墙亮度约 160、梯度 2.2；《地下室》户外窗前亮度约 79、梯度 3.7；正常成片取景头顶 y≈573–615。自动选的那套如果这一处放不下，会停下说明，按提示改 `job.json` 换一套。

**花字.json 写法**（和别的组件放在同一个列表里）：
```json
{"use": "人挡字", "text": "万兆", "at": "万兆", "until": "虽然现在", "小字": "第二件事 · 网络", "风格": 2}
```
`at`、`until` 和别的组件一样写口播原话或秒数；也可以不写 `until` 写 `"时长": 秒`（都不写停 3 秒）；`小字`（上方一行小字，杂志刊名常用）和 `风格` 可选。最短 = 出场＋停留 1 秒＋淡出（约 2–2.5 秒）。
**单条调位置**（可选，用户说“字往上一点”“字再大一点”时用）：`"字顶": 300`＝大字字墨顶的 y（4K 像素，越小越高，最高到导航条下 26 像素）；`"字宽": 0.94`＝大字占画宽的比例（越大字越大，人挡住的那几个字挡得越少）。写了就按写的放、不再自己找；按写的放不合格（有字挡过一半、压到字幕）就停下说清楚。

**规矩（程序里拦，不合格就停下、一段都不出）**
1. 只给特别重点用：一条片子最多 **3 处**、两处之间至少 **20 秒**（`job.json` 的 `"人挡字上限"`、`"人挡字间隔秒"` 可调）。**紧挨着的几条**（前一条的 `until` 就是后一条的 `at`，相隔不超过 2 帧，比如“设计经验”接着换成“现场调试”）算连着换字：只算一处、不查间隔，不用改 `人挡字间隔秒`；两条时间重叠会停下（花字轨上重叠的后一条放不上去）。
2. 必须在露脸段：整段落在 `分镜.json` 的 F 镜头里，不能压到 B-roll/动画镜头；没有 `分镜.json` 先跑 beats。
3. 同一时刻不放别的花字（花字轨只有一条，人挡字又是整幅画面）；它不参加普通花字的 3 秒间隔提示。
4. 只支持 3:4、29.97 帧（A肉 必须是 3:4）。

**自检**
- **遮挡按每个字算**（2026-11-21 用户：“中间那 2 个字被稍微挡住一点，比如挡住一半或者 1/3”“虽然要挡住，但是不能被挡住的字完全读不出来”）：每个字的字墨被人物遮罩盖住的比例，逐帧算、去掉出场段和淡出段，每个字取 95 分位（抠像偶尔一两帧抖不算）。合格＝**每个字都不超过一半**，且被挡最多的那个字至少有一点（1 苹果式 6%，其余 8%，再少不像人挡字）。结果记进 `花字表.json` 的 `遮挡`（`每字`、`最挡`、`说明`；`平均` 是整体字墨的被挡比例，只作参考）。不合格：`huazi.py` 写完花字表后停下并给建议（写 `字顶`/`字宽`、换时刻、换风格），`review` 不放、`check` 列为一项。
- **出片前先预查头顶空间**（2026-11-21《装修最后那点细节》：近景自拍头顶贴画面上沿，“补不回来”出到那一条才发现放不下，只能改人前 koubo）：写完 `花字.json` 跑 `huazi.py`，它在出任何片段之前，先把这次要出的人挡字都按底片（`A肉.mov` 或 `A肉_人像下移<值>.mov`）里的人像找一遍位置；有放不下的，一次全列出来（第几条、时间、字、头顶离画面上沿多少、要多少才放得下、试过哪些放法）并停下，一个片段都不出。照提示把这几条改成人前的 `koubo`；一定要人挡字就换一个头顶空间更多的时刻或换短词，再重跑。
- **找位置**：先用遮罩量人头顶的位置，出片前就按上面的判定（在抽出的 30 帧遮罩上算）找一个合格的位置。默认放法是大字压在头顶（字下部按这套的比例压进头里）；不合格时按这套风格写好的顺序试：**下移到头后**（这套允许的最高位置）→ **上移**（一步步往上挪，最高到导航条下 26 像素；头顶离画面上沿很近的取景靠这一步）→ **放大**（苹果式、对焦字 120%，杂志刊名 105%＝94% 画宽，字大了人挡住的那几个字挡得少）→ **缩字**（85%、70%，字号不小于 200，不缩成看不清的小字）→ **改放头侧**（整个词放在头的一边，不拆到头两侧；苹果式、对焦字有）。放大、缩字也按“头顶→头后→上移”找位置。都不行就停下，说明每种放法为什么不行、每个字挡了多少，不硬放。退路写在 `rendang.py` 的 `STYLES[...]['fallback']`。
- **改了就重出**：同名片段的 `.json` 里记着签名（帧位置、字、风格、这套风格的全部参数、判定规则、`字顶`/`字宽`、底片文件名），改了其中任何一样，下次跑 `huazi.py` 自动重出，不用手删。11-21 以前出的老片段签名里没有参数，原样沿用、不因为升级重出。
- `check` 还会查：分镜改过后人挡字压到了非露脸镜头、口播画面（`A肉.mov` 或 `A肉_人像下移*.mov`，花字表 `底片` 记着是哪个）比人挡字片段新（重出过要重出人挡字）。音效对画面：人挡字只认大字出场那几帧（整幅画面一直在动不算）。

**字体例外**（2026-11-13 用户定）：人挡字可以不用苹方、不限蓝白两色，用 `<程序目录>/素材库/字体/` 里的开源字体（思源黑体 Heavy/Light、思源宋体 Heavy、Inter Display，均 SIL OFL，许可证和来源在同一文件夹 `来源说明.txt`）。程序按文件路径加载，**不装进系统**；缺字体会停下说去哪下载。

**要多久**（4K、Mac mini，2026-11-14 实测 2.4–2.6 秒的一段）：第一次（含 RVM 抠像）17–21 秒；改字、换风格重出这一段（抠像缓存命中）约 12 秒。只重出某一处：`huazi.py <片子目录> --only 3`。
