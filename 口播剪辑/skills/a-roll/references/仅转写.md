# 仅转写（只要文字、不剪）

`python3 bin/transcribe_video.py --video <原片> --work-dir <本机新目录>`：本机提音、直传豆包，结果只存本机（`转写预览.txt`、`doubao_turbo.json`、`transcription_manifest.json`、`timings.json`）。
- 多音轨先试听，用 `--audio-stream N`（从 0 开始）明确选轨。
- 中断后用同一视频、同一目录重跑。默认抽样校验原片并完整校验提音，`--full-source-check` 才完整哈希原片。
- 时间为 `-1/-1` 的空格项不能用作切点。
- 旧目录缺校验信息时保留原数据，请用户核对（换新目录会再计费）。
- 提示“上次请求没有完整结果”时，用户确认核对过用量才加 `--retry-uncertain`，不自动重试。
