# 封面（`cover/`，thinkcut-cover）

品牌风格的装修/设计类视频封面。画风是单线插画，只给本期主角上蓝色（底图按陶土色画，排版时换成蓝色）；主标题用宋体；副标题放在色块里，用红橙手画箭头指向主角，可用红橙手画圈圈住标题关键词。一期讲四样东西时用四宫格版式；另有左右对比（错的 vs 对的）、数字大字、三步流程、局部放大四种版式（2026-11-14）。副标题可以不要（2026-11-21）：不画色块，红圈圈标题关键词、红箭头从圈指向主角。每期 3:4 出 3 个方向，AI 先挑一个把 4:3 和 16:9 出齐，用户在审片台事后选、改（2026-11-22 起），横版默认复用竖版那张画，不另生图。

另有“实拍留色”画风（2026-11-20，`init … --style photo`）：底图是黑白照片、只有问题部位保留彩色，标题、色块、红橙圈和箭头同上，照片不调色；单主角、四宫格、左右对比、数字大字、局部放大都能用，另有竖图满版、三联竖条、拍立得拼贴、六宫格四种只给实拍的摆法（三步流程暂不支持）。

## 怎么用
在 Claude 或 Codex 里说"做封面"，然后给出主标题（一般两行，三行也可以）、副标题，并说明这期讲什么。Skill 名是 `thinkcut-cover`。完整流程和规则见 [skill/thinkcut-cover/SKILL.md](skill/thinkcut-cover/SKILL.md)。

## 新 Mac
```bash
bash bin/setup_mac.sh
codex login
bash bin/run_tests.sh
```
前两步各做一次。`run_tests.sh` 不生图，也不消耗额度。

## 目录
| 路径 | 内容 |
|---|---|
| `skill/thinkcut-cover/SKILL.md` | 定稿规范与操作流程 |
| `skill/thinkcut-cover/scripts/thinkcut_cover.py` | 登记、生图任务（`gen`）、排版与质检（`render`） |
| `skill/thinkcut-cover/assets/` | 画风参考图 `style_ref.png`（只给人看，生图不再使用）、华文仿宋字体（已停用） |
| `samples/` | 单主角版和四宫格版的样例底图和文案，离线测试用（子文件夹名带片子内容） |
| `samples/设计过程/` | 当初选画风、选排版的对比图 |
| `samples/无副标题与横版复用_验收/` | 2026-11-21 验收总览：无副标题各版式、横版复用竖版画、画被裁自动缩小上提的前后对比、圈问号的量法修正前后 |
| `samples/实拍留色_验收对比/` | 实拍留色固化时的验收总览：14 版旧成图和技能重出的并排对比、各版式三种比例 |
| `bin/` | `setup_mac.sh` 接入新 Mac，`run_tests.sh` 离线测试 |
