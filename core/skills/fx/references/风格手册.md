# 花字风格手册

2026-10-24 用户定：分叉前带来的别人的花字规则全部去掉，花字从自己的两条片子里提取——《老房排气道反味》（261015）和《精装房为什么会臭气熏天》（261022）。以后定稿的新案例补进文末索引；改规则要用户同意。

## 片子里的文字怎么分工

- 讲解文字主要靠两样：**新样式字幕**（thinkcut-edit 第 3 步）和**动画里的标签**（见 `$AI/studio/skill/thinkcut-edit/references/动画风格.md`）。
- 两条片子都**没有口播强调大字**。《烟道》整条没有单独的花字轨，文字全在动画和字幕里。没有用户要求，不加口播花字。
- 花字只用在**实拍画面上点名具体部件或品牌**的时候，做成跟随标签（下一节）。
- **样式统一到包装系统**（2026-11-12 用户定，取代原来的“蓝底 #2F7BFF、冬青黑体、对比标签主题橙 #FF6F00 底”）：苹方 SC 中粗、颜色只用白和唯一强调色 #64A9E8、默认不加底只有柔和投影；橙色只留给包装系统里的下划线和手画圈，红 #FF5C5C 只给口播大字〖〗反面词（这两样 Text+ 都不做）。

## 达芬奇 Text+ 花字和包装系统怎么分工

- **达芬奇 Text+ 花字**（`fx.py build`，样式 `brand_label` / `brand_label_dark`）：要在达芬奇检查器里**直接改字**的、要**跟随物体**的（跟踪按 [写入与交付.md](写入与交付.md)“使用 Fusion 时”做）标签和对比标签。样式和包装系统同字体、同颜色、同投影，对比图见 [Text+花字_包装系统对比.jpg](Text+花字_包装系统对比.jpg)。
- **包装系统**（`huazi.py`，出好的透明 ProRes 放“花字”轨）：数字强调、关键词、口播大字、金句、评论弹窗和所有信息卡片。改字要重出。
- 同一个画面只用一边，不叠。
- 用户要口播花字时（2026-10-31《别墅地下室防水》起），只用包装系统里的「口播大字」（koubo）：2026-11-12 起苹方中粗、柔和投影、0.40 秒进 0.30 秒出；`【】`重点词浅蓝 #64A9E8，`〖〗`反面词红 #FF5C5C；**有花字的那段去掉字幕**。

## 跟随标签（《精装房》通气阀品牌 Oatey / Studor，2026-10-23）

- **样式**（2026-11-12 起，按包装系统）：苹方 SC 中粗白字、**不加底、不带小三角**，柔和投影（黑 67%、下移约 6px、模糊约 12px）。实拍画面太花、白字看不清时，先挪到暗、空的地方；挪不开才加深色半透明胶囊底（#101216、66%，同 `brand_label_dark`）。原来的蓝底 `#2F7BFF` 胶囊＋小三角、冬青黑体不再用。
- **尺寸**（4K 竖版 2160×2880）：字号 76px（字身，和包装系统“引线标注”同大；2026-11-12 架构审查验收后从 104px 改小）；字的下沿在物体顶部上方约 70px；左右离画面边至少 120px（包装系统安全区）。别的画幅按画宽等比换算。
- **动作**：按包装系统统一节奏：0.40 秒缓出进场（透明→不透明、上移 28px），0.30 秒缓入出场；不再用 1.12 倍弹回（包装系统禁止弹跳、回弹）。达芬奇 Text+ 花字也一样默认这样淡入淡出（2026-11-12 用户看对比片后定，取代 10-16 的“默认静态”；用户明确说要静态的才不加），只做透明度和位移，不做模糊。
- **跟随**：逐帧跟踪物体位置，前后各 3 帧取平均防抖。
- **位置**：同屏最多 2 个；避开顶部导航条、底部字幕区和人脸小圆圈（和动画标签一样）。
- **停留时长**：跟着那句口播的长度走——从说到这个部件/品牌的那句开始，到这句说完结束，像《精装房》那组停了 65 帧（约 2.2 秒）（2026-10-24 用户定）。不套动画标签“至少 2.5 秒”的规定。
- **做法**：两条路都行，样式一样。①要在达芬奇里改字：`fx.py build` 写原生 Text+ `brand_label`，跟踪按 [写入与交付.md](写入与交付.md)“使用 Fusion 时”做。②程序画整帧透明 ProRes 4444（和章节导航条一样），放审核线最上面一条视频轨「花字」，x=0、y=0 铺满全帧；参考《精装房》的 `<片子文件夹>/finish/261022 精装房为什么会臭气熏天/02_制作/自动剪辑/花字/render_labels.py`（画标签，里面还是旧的蓝底样式，照抄前先换成包装系统 `huazi.text_img`）和同目录 `track_valves.py`（跟踪）。

## 在达芬奇里直接打字的样式（brand_label / brand_label_dark）

`fx.py build` 写原生 Text+ 时只有这两个样式（`engine/config/fx_styles.json`），2026-11-12 统一到包装系统：

| 样式 | 什么时候用 | 样子（4K 竖版） |
|---|---|---|
| `brand_label`（默认） | 标签、对比标签、实拍里点名部件或品牌 | 苹方 SC 中粗白字（Text+ 里写 `PingFang SC / Semibold`），字身 76px（Size 0.0616，和包装系统引线标注同大），**不加底**，柔和投影（Text+ 着色元素 3：黑、不透明度 0.67、偏移 0/−0.045≈下移 6px、柔化 10） |
| `brand_label_dark` | **只在实拍画面太花、白字＋投影看不清时**，而且先试过挪到暗、空的地方 | 按包装系统“提示”胶囊做：苹方 SC 中等（`PingFang SC / Medium`）64px（Size 0.0519），深色半透明底（着色元素 2：#101216、不透明度 0.66、全圆角；高 114px、字两边各留 42px），不加投影 |

两种都只用白字；需要强调色时只能用 #64A9E8，不用黄、橙、红底。冬青黑体、蓝底 #2F7BFF、主题橙 #FF6F00 底已于 2026-11-12 去掉。
**已在达芬奇实测校准**（2026-11-12，达芬奇 21.1.1，测试工程 2160×2880）：Text+ 里苹方按行高排字（字身＝Size×画宽×0.8×1000/1400），字墨四边误差 ≤1px；投影偏移单位是“Size×画宽”，柔化 10 约等于包装系统的 12px 模糊；深色底的框按实测写进安全检查。只校准了居中单行；多行或改对齐要重新实测。和包装系统并排的对比图：[Text+花字_包装系统对比.jpg](Text+花字_包装系统对比.jpg)。
