# 配 B-roll

**可以使用 Fusion**（2026-10-23 用户定）：跟踪、抠图、背景模糊等需要 Fusion 的效果可直接用，普通花字仍优先剪辑页 Text+。详见 AGENTS.md。

**用户改过的素材整项不再改**（2026-10-17 用户：“只要是我改过的素材都不要再改了。”）：见根目录 AGENTS.md「用户手工定稿保护」，全文照做。配 B-roll 怎么辨认手改、怎么排除，见[写入与核验](references/写入与核验.md)「写入前对账」「只动自己的片段」。

选镜头或复盘手改时，先确定这句要展示的动作、内容与证据，再选素材；人物实拍也可作 B-roll，不以覆盖率替代叙事。
配之前先按口播句子查历史素材：`python3 bin/library.py find "这句口播"`（素材库，跨期找实拍和动画镜头，返回路径、描述、用在哪期哪句、匹配理由）；本期不够、要用别期素材时，直接用 `plan --folder '<那条素材所在目录>'` 加进候选，不先问（2026-11-22 用户定“先做出来再改”），交给用户时说明哪几处用了别期的素材。
工作台＝本 Skill 文件夹真实路径往上两级；读根目录 AGENTS.md，在工作台运行命令，输出留在项目目录。
用户先打开达芬奇工程，默认当前时间线；命令自动自检环境，plan/apply/adjust 开头先接管旧 AI 片段、对照台账认出她已有的手改（对账），不要求 thinkcut-edit「剪口播」 finish。
所有命令前缀为 `python3 bin/broll.py`；`status` 只读确认工程、时间线、工作目录，不创建目录、不写台账，推不出项目或创作者时一次只问一个问题。
配画面先读[看图与匹配](references/看图与匹配.md)、[排布](references/排布.md)，写入前读[写入与核验](references/写入与核验.md)；报错读[故障](references/故障.md)。
用户说配 B-roll、或交来一条新项目任务（2026-11-22 用户定：新任务五项一起做成初稿，不问）即授权当前主线写入；涉及她手改的位置照旧不动，整片重铺已有的 B-roll、覆盖率降超15个百分点时先问一句；时间线不明确时用主线（最新的 `v*_主线_*`），并说明用的是哪一条。
## 保留原素材名称

插 B-roll 直接使用媒体池原文件夹里的原素材，按源入点裁切；保留源文件名、媒体池片段名和时间线片段名，方便用户反查原文件。不为插入而复制、重命名素材，或生成改名的替代视频；镜头说明、运行编号和 AI 归属写入备注或台账。

`apply/adjust` 普通视频和照片直接引用原素材；池外普通素材从原路径导入。HDR、可变/未知帧率及暂不支持直接放置的源帧率才转换，衍生文件名保留原文件名，台账记录源路径、源入点与转换原因；Log 缺可靠 LUT 时跳过。离线回归不代表实机验收，详见[写入与核验](references/写入与核验.md)。

## 她的说法 → 命令
表内 `<编号>` 由 `at` 定位，`<匹配文件>` 由 Codex 看图填写；调整前后只处理点名处。
| 她的说法 | 命令（由 Codex 执行） |
|---|---|
| 剪 B roll / 配 B-roll / 插画面 / 再配一次 | `plan` → 看第一层素材、填匹配；不足或用户要求补其他项目时 `plan --more` → `apply --matches <匹配文件>` 演练 → 同命令加 `--apply` 写入 |
| （apply 报“没有叠加层下方的空闲主选轨”：主线只有口播一条画面轨） | `add-track` 演练 → 同命令加 `--apply`：在最上面加一条空画面轨“B-roll”并保存工程，不动片段，再重新 `apply`。已有能放的画面轨不加；上面有花字、人物抠像等叠加轨时不加（脚本只能加在最上面），请她在达芬奇里手动插（2026-11-28） |
| 这处（播放头 / 时间码） | `at --playhead` / `at HH:MM:SS:FF`；不唯一时最多列3处供选 |
| 这处换掉 | `adjust --spot <编号> --use 2 --apply`（或 `--use 3` / `--segment <素材段ID>`） |
| 这处不要 | `adjust --spot <编号> --remove --apply` |
| 这里留空 | `adjust --spot <编号> --reserve --apply` |
| 这句露脸 | `adjust --spot <编号> --face on --apply` |
| 这处开原声 / 关原声 | `adjust --spot <编号> --audio on --apply` / `--audio off` |
| 这处画面偏上 / 偏下一点（衍生片段） | `adjust --spot <编号> --crop-anchor 0.3 --apply`（0 最上/最左，0.5 居中，1 最下/最右；只重出这一段） |
| 撤销刚才 | `undo --apply` |
| 旧版更好 | `undo --apply`；撤销失败先停下 |
## 汇报
只在保存、重开、读回通过后说“已铺 N 处，在原主线看”；局部修改另有短审核线，改动请回原主线。
演练、写入和局部调整都逐处列 `时间码｜句子｜素材文件名｜源入点（帧与时间码）`；跳过处只给一个具体原因：用户画面、保留位（她删/换/停用/剪掉/章节停用V1/点名留空）、露脸、已有AI，或裁后太短（实际帧数<最短帧数）；候选质量/黑名单/素材不足等按实际规则说明。另报覆盖率前后、匹配遵守率，以及被过滤的候选ID和规则名；按台账说明备选和原声状态。写入前必须打开演练输出的 `演练核图/<run>.jpg` 逐镜核对，核对通过再写入。
出错按“出错了：原因；下一步：由我处理的动作 / 需要你确认的一件事”说明；未核验不说完成，回滚未核验不说已恢复。
需要多项时按 thinkcut-edit「剪口播」 → thinkcut-edit「配 B-roll」 → thinkcut-edit「花字音效」；手剪口播也可直接配 B-roll。
离线测试不等于实机或用户验收。
