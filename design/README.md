# 界面规格 v1（2026-11-26 定稿）

ThinkCut 所有界面（首页、审片台各栏、口播精剪编辑器、设置页）的颜色、线、圆角、阴影、字号、间距、动效只在一处定义：本目录的 `tokens.css`。页面里不写死颜色和这些数值，`bin/test_design.py`（全套测试 `bin/test_all.py` 会跑）发现页面绕过规格就不通过。

- 设计稿（定稿，Claude Design 画布）：https://claude.ai/artifact/4NA4TyvfJFMXF7higWU8r5 。每一版的链接和全部画板图片存在 `/Volumes/work/Dev/ThinkCut/设计存档/<日期 名称>/`（本版：`2026-11-26 界面精修 v1/`）。以后大改风格新开一个文件夹、规格改名 v2，旧版留着对照。
- 样张：双击打开 `样张.html`，它直接用 `tokens.css` 的变量画出全部零件；改了规格，样张跟着变，先在这里看效果再看页面。
- 规格怎么进页面：页面里写一行 `<!--THINKCUT_TOKENS-->`，服务发页面时换成 `tokens.css` 的内容（`studio/skill/thinkcut-edit/scripts/thinkcut/design.py`）。Mac 外壳自己的提示页编在程序里读不到这个文件，值是抄的（`bin/app/ThinkCut.swift` 的 `notice`），改规格时一起改。

## 规矩（每条怎么用）

1. **颜色**：主体全用中性灰。`--win` 窗口底、`--bar` 顶栏和细栏、`--side` 右边意见栏、`--surface` 正文区、`--card` 卡片和浮层、`--sunk` 引用块和只读框；字只有四档：`--t1` 正文、`--t2` 次要、`--t3` 说明（最浅的可读字）、`--t4` 禁用和占位。深色模式单独调了一套，不是反色。
2. **蓝只给能点的和选中的**：主按钮 `--blue`（悬停 `--blue-h`、按下 `--blue-p`）、蓝字和链接 `--blue-t`、选中底 `--blue-tint`、当前句 `--sel`、键盘聚焦光圈 `--ring`。不拿蓝色做装饰。
3. **状态色**：只有四个状态（待审阅 蓝、待提交 橙、AI 处理中 紫、已定稿 绿），外加出错（红）和未登录/灰。每个状态三个值：`--s-x` 实色小圆点、`--s-x-t` 文字、`--s-x-bg` 极淡底。标签＝6px 点 + 12px 中粗字 + 淡底；顶栏里的状态不带底，悬停才加 `--fill`。AI 不在线时提交的意见写“已存下 · 等 AI 上线”（紫色、空心点），不同时写“处理中”和“离线”。
4. **发丝线**：一律 0.5px 半透明（`--hairline`、`--hair`、`--hair2`），不用 1px 灰实线。
5. **圆角只有 4 档**：`--r-s` 6 小控件（分段格、小按钮、输入框、标签）、`--r-m` 8 按钮和分段外框、`--r-l` 12 卡片和面板、`--r-xl` 14 浮层和弹窗；胶囊用 `--r-pill`；浮层小箭头的尖、细进度条两头用 `--r-tip`（2px，不算一档）。嵌套时里层 = 外层 − 内边距。
6. **阴影只有 3 档**，每档两层（紧贴细影 + 很淡散影）：`--sh1` 贴边（卡片）、`--sh2` 浮起（悬停、拖动中）、`--sh3` 弹窗（浮层、菜单）。卡片用 `--sh-card`（发丝线 + 贴边），浮层用 `--sh-pop`，次按钮和输入框的边用 `--sh-btn`。不用大虚影。
7. **字**：`--font`（中文苹方、英文数字 SF，系统自动配），数字一律等宽（`tabular-nums`）。字号只有 11/12/13/15/20/28（`--fs-*`，配 `--lh-*`），字重只用常规 400 和中粗 600。例外：文稿、审片、口播精剪的正文阅读字号由用户 A−/A+ 调，不进字号表。
8. **间距**：4 的倍数（`--sp-1` 4 … `--sp-10` 40），左边缘对齐。顶栏高 `--bar-h` 52、细栏 `--sub-h` 44。
9. **分段控件**（顶部栏目、看板/列表、倍速）：底 `--seg`、外圆角 8、内边 2；选中格 `--seg-on` + `--seg-on-sh`、圆角 6、中粗；悬停只加 `--fill`；未开始的栏字 `--t4`。栏目可以按住拖动换顺序，右键“恢复默认顺序”。
10. **按钮**：主按钮蓝底白字；次按钮 `--btn` + `--sh-btn`；浅蓝按钮（提意见类）`--blue-tint` 底 `--blue-t` 字；文字按钮透明 `--blue-t`。禁用＝灰底灰字（`--fill-h` / `--t4`），不是蓝色变淡。高 28，小号 24。
11. **空白页**：整块内容区居中：图标方块 + 20px 标题 + 一句说明 + 下一步按钮。不缩在角落里，不留看不出用途的空白。
12. **图标**：一套线性图标，16 格、线宽 1.5、圆头圆角，颜色跟字（`currentColor`）。
13. **动效**：`--dur-1` 0.15 秒（悬停、按下，只变底色）、`--dur-2` 0.2 秒（浮层出现：淡入 + 上移 4px + 0.98→1）、`--dur-3` 0.25 秒（栏目滑块、大块内容切换），同一条曲线 `--ease`。位移量乘 `--move`：系统开了“减少动态效果”时它是 0，只剩淡入淡出。
14. **浮层**：挂在触发它的按钮下面、带小箭头、离窗口边至少 16px，放不下往里挪；点外面或 Esc 关。
15. **顶栏让位**（2026-11-27 用户：“文稿、口播精剪这个切换肯定要能保啊……Claude和达芬奇在线可以浓缩成一个图标，或者改小”）：按**顶栏自己的宽度（＝主区宽度）**判断，不看窗口宽——对话侧栏打开、主区变窄时跟着让位；用容器查询（`container:tb/inline-size` ＋ `@container tb (max-width:…)`），不用脚本，开合侧栏不跳。
    - 永远完整显示：**栏目切换**（最优先，不许被裁掉）、主按钮（提交 AI／定稿／新建项目）、“对话”开关、帮助“?”。
    - 宽度不够时依次让（审片台的阈值）：≤1360 收起“待审阅 N”合计 → ≤1180 AI 引擎、达芬奇两个状态收成带颜色的小圆点（悬停看全称和状态，点开照样能换 AI、看达芬奇）、项目名下面那行小字收起 → ≤1000 栏目里的件数收起（只留栏名） → ≤860 “对话”只留图标、主按钮去掉最小宽 → ≤720 项目名截成省略号 → ≤600 项目名只剩“全部项目”图标，栏目改成可横向滚动（两头淡出示意还有），当前栏始终滚到看得见的地方。
    - 首页同理（阈值更宽松，因为东西少）：≤1000 收起合计 → ≤860 AI 状态收成小圆点、“思刻”收起 → ≤720 “对话”只留图标、“设置”只留齿轮、IP 名截短 → ≤560 程序名收起、“新建项目”只留“＋”。看板／列表切换一直在。
    - 对话侧栏：主区还有 560 以上时把页面推开；不够时浮在页面上面，并且从顶栏下面开始，不盖住顶栏。
    - 自查截图：`/Volumes/work/Dev/ThinkCut/截图与素材/顶栏响应式自查/`（主区 700、900、1100、1400，侧栏开／关，浅／深，另有 560、480 当前栏在最右的、Mac 程序里的）。

## 改规格

只改 `tokens.css`；改完双击 `样张.html` 看，再跑 `python3 bin/test_design.py`。加新变量要在 `README.md` 这里补一句怎么用。规格名（`--tc-spec`）大改时升版本号。
